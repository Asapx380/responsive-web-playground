# Responsive Web Playground

Landing page responsiva de prática (HTML + CSS), feita no início dos estudos de front-end.

## O que tem aqui

- Layout de marketing com header, hero e tipografia customizada
- CSS puro (sem frameworks)
- Estrutura simples para treinar responsividade e hierarquia visual

## Como abrir

Abra o `index.html` no navegador ou use um servidor local:

```bash
npx serve .
```

## Stack

- HTML5
- CSS3
- Google Fonts
